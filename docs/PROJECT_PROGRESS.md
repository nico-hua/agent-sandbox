## 待优化问题

- workspace 可持续增长，尚无配额或自动清理；文件传输尚未完成持续高并发内存压测。
- SSE 仅支持前台请求，不支持重连、事件重放或后台日志；断线或慢客户端可能收不到终止帧。
- 容器资源上限仍为固定值，运行中命令随容器停止的优雅退出行为尚未完整验证。
- CommandRunner 在 Agent 所在环境执行进程，本身不提供隔离；当前取消清理没有退出宽限期，也无法覆盖逃离进程组的后代。
- 输出按 stdout、stderr 分别限制原始字节，尚无总额度，也不约束调用方的输出存储。
- 命令并发限制仅作用于单个 Agent，尚无跨实例、用户或优先级调度。
- 环境变量不支持删除，传入的 `PATH` 不改变初始可执行文件的查找规则。
- 尚未建立正式威胁模型或完成隔离边界验证。
- Docker 与 SQLite 没有跨系统原子事务，部分失败仍需同 ID 重试或人工核验；数据库记录不代表实际实例存在。
- 周期回收仅支持单进程、单 worker，到期删除存在扫描和重试延迟；Docker 标签仅保存初始时间，保留 workspace 仍需显式删除。
- 既有真实 Docker 验收环境为 Linux/WSL Python 3.12；本次异常优化在 Windows/Python 3.14 运行默认回归，未重新执行真实 Docker 集成。
