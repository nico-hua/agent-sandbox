# 项目开发进度

本文档记录 Agent Sandbox 已完成的开发工作、后续功能和已知优化事项。开发进度按日期倒序排列，最新记录位于最前。

## 开发进度

### 2026-09-23

- 为 CommandRunner 增加独立的标准输入参数，支持文本、多行和二进制数据原样传递；nil 输入保持 EOF 语义，不继承 Agent 终端。
- 增加 stdout/stderr 单流字节上限，支持无限制、参数校验、独立额度以及 nil writer 输出计数。
- 输出超限时通过内部 context 复用进程组终止逻辑，并区分输出超限、主动取消、执行超时和用户程序非零退出。
- 增加有限输出、无限输出、并发超限和后代进程清理测试。
- 为 Linux/WSL CommandRunner 增加独立进程组管理，避免取消命令时误杀 Agent 所在进程组。
- context 取消或请求超时时，通过向命令进程组发送 `SIGKILL` 终止直接子进程及仍在同一进程组内的后代进程。
- 增加父子进程启动同步、进程组隔离、整组终止和进程退出回收测试。
- 为 CommandRunner 增加调用方 `context.Context`，支持启动前取消、运行中取消和父 deadline。
- 增加请求级 `Timeout`，覆盖零值、正数、负数以及父 context 优先语义。
- 验证取消后的直接子进程已经结束并被回收，且取消错误不会被误判为普通非零退出码。
- 为 Go CommandRunner 增加继承、覆盖和新增子进程环境变量的 `Env` 支持。
- 验证空值覆盖、字面量传递、Agent 环境不变以及 `Env` 与 `Cwd` 同时生效。
- 为 Go CommandRunner 增加可选的 `Cwd` 工作目录支持。
- 验证指定工作目录、相对路径、默认继承工作目录和无效目录的行为。
- 在项目协作指南中补充函数注释、函数长度和职责拆分规范。
- 将原 Changelog 整理为统一的项目开发进度文档。

## 待优化问题

- 当前 CommandRunner 直接在 Agent 所在环境启动本地进程，不提供 sandbox 隔离。
- context 取消和 Timeout 使用 Linux 进程组及 `SIGKILL` 清理进程；当前没有 SIGTERM 宽限期，也无法清理通过 `setsid` 等方式逃离进程组的后代进程。
- 输出限制当前按 stdout 和 stderr 分别统计原始字节，不解释文本编码，也不限制调用方 writer 自身的存储方式。
- CommandRunner 测试面向 Linux/WSL，并依赖 `sh`、`printf`、`pwd` 和 `cat` 等系统程序；尚未覆盖其他平台。
- `Request.Env` 尚不支持删除变量；其中的 `PATH` 也不改变 `Argv[0]` 的初始可执行文件查找规则。
- 项目尚未建立正式的威胁模型，也未验证资源、文件系统和网络隔离边界。
